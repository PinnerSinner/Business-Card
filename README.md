This project delivers a visually striking developer profile card featuring:

- Clean, dark-themed design with distinctive orange accents
- Subtle 3D transform effects and hover animations
- Responsive layout that adapts to all screen sizes
- Social media integration with custom icon styling

Tech Stack

## HTML5
CSS3 (no frameworks)
Font Awesome icons
Custom CSS animations and transitions

## Features

Visual Design: Dark mode with orange highlight theme
Interactive Elements: Social icons with hover effects
Skills Display: Clean tag-based skill presentation
3D Effects: Subtle depth and perspective on interaction
Responsive: Seamlessly adapts from mobile to desktop

# Usage

Clone the repository
Replace marco.jpg with your own profile image
Edit the HTML to update your personal information and links
Customize the CSS if you want to change the color scheme
